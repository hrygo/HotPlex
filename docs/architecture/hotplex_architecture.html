核心技术亮点

    为什么要为你的 AI Agents 选择 HotPlex？

    🌐

    AEP v1 统一通讯基准

    采用自研 Agent Exchange Protocol v1 WebSocket 协议，抹平各种 Agent (如 Claude Code、OpenCode) 输出流、状态迁移和交互语境的异构性，实现一套标准、全端分发。

    🧠

    独创 B/C 双通道上下文注入

    B 通道强制注入宪法级元认知防御指令 (META-COGNITION)、人设 (SOUL) 与规则，防止攻击注入。C 通道热插拔用户上下文 (USER) 与压缩的历史记忆 (MEMORY)，给 Agent 最精准的大脑。

    ⚡

    AI 原生定时任务引擎

    支持 Agent 直接利用自然语言在后台编排、创建并托管定时作业。通过 sqlite 持久化、Tick Loop 控制并发与 CAS 锁定、执行指数退避重试，结果异步安全投递回 Slack 或飞书卡片。

    🛡️

    物理沙盒与高可用进程控制

    针对 Coding Agent 编写代码的潜在崩溃与死锁，HotPlex 在跨平台层面封装了 Unix PGID 进程组与 Windows Job Object，具备 3 阶段温和注销序列，彻底告别后台僵尸进程。
